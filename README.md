# Descripción del proyecto
Este proyecto simula servicios de administración de empresas con sus respectivas sucursales, permitiendo corroborar datos, gestionar productos, y acceder a información almacenada en una API alojada en la nube. El flujo de trabajo incluye:
- Creación de modales, tarjetas (cards) y páginas según los requerimientos.
- Uso de la carpeta types como referencia para las interfaces.
- Implementación de fetch en los servicios de cada elemento, necesarios para la comunicación con la API.
# Instalaciones necesarias
Puedes instalar las dependencias necesarias de dos maneras:

## 1. Instalación individual
Ejecuta los siguientes comandos uno por uno:
```
npm install @reduxjs/toolkit
npm install axios
npm install bootstrap
npm install react
npm install react-dom
npm install react-icons
npm install react-redux
npm install react-router-dom
npm install react-select
npm install sweetalert2
```
## 2. Instalación masiva
Si prefieres instalar todo de una vez, ejecuta:
```
npm install
```
# Verificación de las instalaciones
Para comprobar que todas las dependencias se instalaron correctamente, utiliza este comando:
```
npm list
```
# Ejecución del programa
Inicia el servidor de desarrollo ejecutando:
```
npm run dev
```
Una vez que el servidor esté corriendo, busca en la terminal un enlace similar a este:
```
➜  Local:   http://localhost:5173/
```
Haz clic en el enlace o cópialo en tu navegador para acceder a la aplicación.
